# image_sorter
一个手动排序后根据顺序重命名的工具
## 背景
经常在网上保存一些图片，但没有经过整理。在图片浏览器中能够以特定顺序浏览图片的最好方法以某种格式重命名需要的所有图片，而网图下载的时候，名称一般没有实际意义，所以制作了这样的一个程序。

## 思路来源
ios中app排列组合动作以及android端firefox标签页的组合动作。

## 具体操作
必须需要说明的是，下面所说的rename，实质上是建立一个新文件夹，将原有图片以新名称复制进去。因为没有考虑好到底该如何处理新命名可能存在的重名现象所以没有原地重命名。

0. 在linux桌面环境下运行release。
1. 在"images dir"中输入图片所在文件夹后，点击右侧的确定按钮，将会在下方的"main panel"中加载所有后缀为"jpeg"、"jpg"、"png"的图片文件。
2. 存在四个直接和图片相关的显示区域，分别被命名为"Main Panel"、"Assist Panel"、"Outer/Unrename Panel"以及"Img Show"。每个图片对应的项存在三种状态，"loading"、"loaddone"、"loaderr"，只有完全加载的图片"loaddone"才可以被拖拽。"loading"和"loaderr"内容上无差异，但显示效果有差异。
3. Panel内的行为。每个Panel内部的图片项为一个图片序列，拖住图片可以视作从当前的序列移除，释放图片可以视作插入新的序列的给定位置，从而完成排序。释放时具体的行为依赖于图片中心和后面图片中心距离的关系。如果差距过大，则认为是插入该图片的前或后；如果差距过小，则认为这两张图片应当被视作同一个组别，而后这两个图片在显示上将被一个“图片组”代替。图片组也可类似单个图片项目被拖拽。
4. 因Panel面积有限，所以每个Panel可以滚动。每个panel有单独的滚动方向，其中"Main Panel"的滚动方向为垂直方向（鼠标滚轮可触发），"Assist Panel"和"Outer/Unrename Panel"的滚动方向为竖直方向（触摸板横向滚动触发）。滚动触发时，鼠标指针必须位于对应的Panel中。在拖拽图片的过程中，如果当前图片拖拽的位置位于滚动方向上显示边界处，可以触发自动滚动。Panel内图片序列的方向和滚动方向相垂直，如"Main Panel"中图片顺序为顶端的左端到右端、下一行的左端到右端……
5. 双击图片组，可以将图片组内的图片加载到主显示区域上，由此可对图片组内图片进行排序或者分组。如果在非输入文本状态下，点击esc，可以回到本图片组外。图片组的名字最初为随机生成的字符串，双击文字区域，可以对图片组名字进行修改。
6. "Outer/Unrename Panel"中可以放置图片。如果是在图片组内，那么在该panel中的图片将会被从该组中移出，放入上一级的"Assist Panel"图片序列中。如果一个图片组内不包含任何的图片或图片组，那么该图片组将会被自动删除。而如果主显示区域为最外层的图片(组)的排列情况时，放置在"Outer/Unrename Panel"中的图片将不会被重命名。在不同层，该panel的名字会有不同。最外层为"Unrename panel"，在图片组xxx内，名字为"Outer xxx panel"。
7. "Img Show"将在其面积中将显示原图片文件的样子，点击对应的图片项即可。如果点击图片组，那么只会显示图标。
8. 在"rename pattern"后可以输入重命名的具体模式。点击确定可以检验当前重命名模式。点击保存可以对当前图片序列情况进行重命名。
9. 本软件采用的命名模式为连续若干个小写英文字符和若干个阿拉伯数字，如"ab01"、"ca99"等为"a2b2"模式（即两个小写字母两个数字字符）下可能的重命名结果，第一个项将被命名为aa00，第二个项将被命名为aa01等等。"Main Panel"将在"Assist Panel"前被重命名。如果为图片组,假设其名称为"xxyy"，轮到的重命名为"ca31"，那么，该图片组内部的图片重名会以相同的模式重新命名，且享有前缀"ca31_xxyy_"。图片组内的图片组会以相同的模式增加前缀。
10. "images dir"和"rename pattern"在输入框内会显示其他的额外警告信息。
